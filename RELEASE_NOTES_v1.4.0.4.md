# ClipFinder v1.4.0.4

ClipFinder has moved to a new GitHub address: **github.com/marsscumbags/clipfinder**

## Changed
- The update check, update downloads and default images now come from `marsscumbags/clipfinder` (the GitHub account was renamed from thatspeedykid to marsscumbags). Older versions still find updates through GitHub's redirect, but this version no longer depends on it.
- Links in the installer and README point to the new address.

## Upgrading
Update from inside the app (banner or Settings → Update Center), or download `ClipFinder-Setup.exe` below.
